# 绕过测试结果

此文件夹包含从绕过安全测试器导出的测试结果。

## 文件格式

结果以 JSON 格式保存，文件命名规则如下：
```
bypass-test_{域名}_{时间戳}.json
```

示例：`bypass-test_cursor_com_2025-09-11_14-30-45.json`

## 文件结构

每个 JSON 文件包含：
- 每种技术的测试结果
- 成功/失败统计信息
- 测试时间戳
- 目标 URL 信息
- 环境详情
- 版本信息

## 状态

⚠️ **开发中**：此工具仍在积极开发中。结果可能有所不同。

## 使用方法

1. 当您在扩展中点击"导出结果"时，结果会自动保存到此处
2. 文件可以导入回扩展中进行查看
3. JSON 格式便于使用其他工具进行处理

## 隐私提示

这些文件可能包含有关测试端点的敏感信息。请谨慎处理，不要公开分享。
